# 🐉 Dragon Studio RD

Motor de videojuegos y editor visual hecho **100 % en Rust**, construido sobre [Bevy](https://github.com/bevyengine/bevy).

> El poder de Bevy, con la sensación de un estudio visual.

## ¿Qué busca?

- **Editor visual** para artistas y diseñadores, sin depender del programador.
- **Rápido**: abre en segundos y recompila en 1–3 s.
- **Android con un clic**, igual de fácil que Windows.
- **100 % Rust**, incluida la interfaz del editor.

Lee la filosofía completa en [dragon/VISION.md](dragon/VISION.md).

## Estado

🚧 En desarrollo temprano. Basado en **Bevy v0.20.0**.

## Estructura

| Ruta | Contenido |
